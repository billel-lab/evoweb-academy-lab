# Ressources — EvoWeb Academy Lab

Liens curatés pour ta formation et ta pratique quotidienne. Pas de liste exhaustive — juste ce qui est vraiment utile.

---

## Apprendre

### Claude Code
- **[Documentation Claude Code](https://docs.anthropic.com/claude-code)** — Le guide officiel d'Anthropic : installation, commandes slash, agents, hooks. Lis au moins les sections "Getting started" et "Core concepts".
- **[Anthropic Cookbook](https://github.com/anthropics/anthropic-cookbook)** — Exemples concrets d'utilisation de Claude en développement. Utile pour comprendre comment bien prompter.

### Next.js
- **[Next.js Docs](https://nextjs.org/docs)** — La référence officielle. Commence par "App Router > Getting Started". Garde l'onglet ouvert en permanence.
- **[Next.js Learn](https://nextjs.org/learn)** — Le tutoriel officiel interactif, gratuit, parfait pour débutants. Complète-le en 1 semaine.

### Tailwind CSS
- **[Tailwind CSS Docs](https://tailwindcss.com/docs)** — Documentation officielle avec exemples interactifs. La recherche (`Ctrl+K`) est ton meilleure amie.
- **[Tailwind Playground](https://play.tailwindcss.com/)** — Teste tes classes Tailwind directement dans le navigateur sans setup.

### TypeScript
- **[TypeScript pour débutants (MDN)](https://developer.mozilla.org/fr/docs/Learn/Tools_and_testing/Client-side_JavaScript_frameworks)** — Pour comprendre les bases du typage avant de plonger dans les projets.
- **[TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)** — Référence complète. Lis les chapitres "Basic Types" et "Functions" en priorité.

### Comprendre le web
- **[MDN Web Docs](https://developer.mozilla.org/fr/)** — La référence ultime pour HTML, CSS, JavaScript. Si tu bloques sur quelque chose de basique, cherche ici d'abord.

## Outils

### Interface utilisateur
- **[shadcn/ui](https://ui.shadcn.com/)** — Composants prêts à l'emploi (boutons, formulaires, modales) à copier dans ton projet. Pas une librairie, du vrai code que tu contrôles.
- **[lucide-react](https://lucide.dev/)** — Icônes propres, cohérentes, en SVG. Cherche une icône par nom et copie l'import.

### Base de données
- **[Supabase Docs](https://supabase.com/docs)** — Guide complet : authentification, base de données, storage, Row Level Security. Commence par "Database > Introduction".
- **[Supabase Dashboard](https://supabase.com/dashboard)** — Ton panneau de contrôle. Tu peux y voir les données, tester les requêtes SQL, gérer les utilisateurs.

---

## Déployer

- **[Vercel Docs](https://vercel.com/docs)** — Tout ce qu'il faut savoir pour déployer un projet Next.js : variables d'environnement, domaines personnalisés, logs. Section "Frameworks > Next.js" en priorité.
- **[Vercel Dashboard](https://vercel.com/dashboard)** — Pour voir tes déploiements, les logs d'erreurs, et configurer les variables d'environnement en production.
